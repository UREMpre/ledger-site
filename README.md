# ledger.615.media

Static files for the Money Laundering iPhone app (bundle `media.615.ledger`): the Apple App Site Association file
that lets `https://ledger.615.media/plaid/oauth` open the app after a Plaid OAuth bank sign-in, and the return page.
Served by GitHub Pages with the custom domain `ledger.615.media` (CNAME at GoDaddy).
